# 🤖 DevLogBot — Interactive Dev Log & Social Brand Builder

DevLogBot is an AI agent built for the Flip to Switch Hackathon that converts raw developer notes in Discord into structured "Build in Public" technical content for LinkedIn and X with human-in-the-loop approval.

## 🚀 Features
- **Instant Technical Content:** Translates messy commit messages or debug notes into structured, engagement-ready social posts.
- **Human-in-the-Loop:** Enforces explicit user approval (`Approve`) before finalizing output.
- **Switch Console Managed:** Integrated with Switch Console room orchestration.

## 🛠️ Built With
- **Language:** Node.js (ES Modules)
- **Bot Framework:** `discord.js` (`v14`)
- **LLM:** Google Gemini API (`gemini-3.8-flash`)
- **Orchestration:** Switch Console
